# Scripted body release

`src/scripted-release.mjs` reconstructs `0x46e4e0`. `releaseScriptedBody(body, {rng, mathScratch, handlers})` either releases a body from scripted motion or installs the unresolved collision filter `0x46e470`. It does not itself remove the body from the physical or spatial lists.

When flags contain `0x2000`, the routine clears integration bit0, writes `(flags & 0xffffddff) | 0x1000`, and constructs a new quaternion from signed-short forward-column entries2/5/8 of the existing rotation matrix. The matrix itself remains unchanged. Real helper `0x41e3f0` normalizes that direction, computes signed half-angle roots and writes quaternion `[cosine, 0, sine, 0]`, preserving native rounding. Caller `mathScratch` optionally retains the final shared fixed-root globals.

The routine then advances caller-owned `rng.seed` once through `imul(seed, 0x41a7) & 0x7fffffff`. All three torque components derive from nibbles of the same resulting multiplied value; this is the exact multiplication/mask sequence, including seed0 remaining0. It calls `handlers.onReleaseEffect({body, code:16})` after flags, quaternion, seed and torque updates, and returns0. Operation `0x46e600` remains an explicit effect boundary.

Without scripted flags, it calls `handlers.onUnscriptedReleaseEffect` with position `[x, y+0x8c0000, z]`, vector `[0, -0x400000, 0]` and native arguments `[1, 0x11229, 11]`; position addition wraps. Operation `0x435ba0` remains an explicit boundary. After that callback, it installs the caller-supplied `handlers.collisionFilter46e470` as the exact `body.collisionFilter` function identity, writes marker `body.collisionFilterNativeAddress148=0x46e470` and returns1. This marker records the original pointer; the filter's implementation is not invented or treated as recovered. A caller must supply the function explicitly.

`node tools/verify-scripted-release-instructions.mjs` passes4,000 full16 KiB body fixtures, split into2,000 scripted releases and2,000 filter installations, plus1,000 independent quaternion fixtures. All304 retained numeric instructions/callees are real; only the two effects are inert callbacks. Checks compare return values, all body bytes, RNG, final root scratch, effect arguments and complete body snapshots at the effects, plus source filter identity and native pointer installation order. Independent helper fixtures compare the mutated direction as well as quaternion and scratch, including large input reduction. Total interpreted steps:3,215,017.

Seven focused tests cover release ordering, cardinal quaternions, large-vector truncation, emitted vectors and filter identity, consecutive release/non-scripted calls, seed0 and singular input. Zero fixed-point direction length, including some tiny nonzero directions, causes native division failure and remains outside successful native fixtures; the source preserves that fault boundary.
