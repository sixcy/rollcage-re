# 2026-10-25 · Surface painting and terrain projects

## Available now
- The Surfaces tool offers searchable thumbnails and an eyedropper for existing static surface presets.
- Painting copies a full native texture/UV/category/grip preset without changing shared descriptors or inventing collision on decorative cells.
- Version-3 projects save sparse height and surface edits together with pickups and scenery; version-1/2 projects remain readable.
- Test changes starts a race from the compiled terrain on racing levels; LEV16/17 offer Preview changes.

## Validation and limits
- Headless Edge checks real brush and paint clicks, undo/redo, cancellation, project round-trip and an edited race restart.
- Sources remain read-only. Game export produces a new archive pair for a separate installation.
- New textures, Blender imports, new sectors and route editing remain future work.
