# 2026-10-25 · Choose any competing reversal branch

- Focus junction now frames all competing branch connections together, labelled A/B/C (and more when needed). Every branch can be selected, including either branch currently occupying a native slot. Nothing is preselected.
- Select a radio choice or click its label in the 3D view. The selected branch becomes amber; the other candidates stay cyan.
- Remove selected branch deletes that connection. Preview nearby free slot proposes a different owner; Move selected branch applies it after inspection.
- Removing or moving a branch already in a native slot gives the freed slot to a waiting branch. The other competing connections are retained automatically, and remaining overflow still blocks racing/export.
- Existing version-6 projects remain readable. Project save/load preserves the repaired connections, report and original draft snapshot.
