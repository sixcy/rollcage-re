Track Viewer changelog

2026-10-25 · Existing-track editor delivery complete

Available now

• All 20 Rollcage levels have combined terrain, surface, pickup, existing race-layout and scenery/effect authoring workflows.

• Version-4 projects save these edits together and load older project versions without losing unchanged special objects.

• Camera controls remain stable while editing, linked drag previews reset correctly, and Focus synchronizes the camera menu.

• The implementation checklist and evidence matrix are linked from the research index.

Validation and limits

• Focused editor regressions, all forty LOW/HIGH source variants, wide route relocation and combined authoring checks pass.

• Browser checks cover real controls, old projects, archive export/reopen, all AI counts and selected special-object paths/lights.

• Six additional native LOW/HIGH cases passed: scenery move/yaw/add/delete initialization, real added-model contacts, and combined special-object/race-layout initialization with all six car spawns.

• Native initialization and selected contacts are bounded evidence. Complete destruction effects, every scripted trajectory, full-track behavior and continuous race parity remain unproved.

• Existing topology and graph counts stay authored; Blender imports and arbitrary new sectors remain future work. Special-object rotation/copy/removal depend on supported ownership rules. LEV16/17 AI racing remains disabled.

2026-10-25 · Scripted scenery, effects and native collision acceptance

Available now

• Original particle emitters and shared-light owners can move with their dependencies. The viewer shows scripted initial poses, selected paths and explicit capability limits.

• Version-4 projects include race layout and all original scenery/effect rows; older projects restore unchanged special rows in native order.

• Dragging a linked group back to its starting point now clears the preview transform immediately.

Validation and limits

• All 3846 original dispatched records across forty LOW/HIGH variants are transformable in the checked corpus, with operation-specific and native capacity limits. Scripted objects support translation; copying/removal remain limited to compatible plain models.

• Native LOW/HIGH checks passed move/yaw/add/delete construction and exact relocated static links. Separate actual car queries hit an added solid model, matching independent geometry replay.

• Browser checks cover special-object history, linked parts, scripted paths, particle focus, shared lights, old projects and zero idle menu mutations.

• These are selected original-game cases, not full destruction, animation or continuous-race equivalence. Terrain validation remains documented in earlier entries.

2026-10-25 · Wider route relocation and checkpoint planes

Available now

• Existing route points can move between supported terrain cells. The editor rebuilds route fallback references while preserving each original route group and collision-model lists.

• Checkpoints are edited as planes. Wire markers show their intersections with the road, and sector references follow supported intersections.

• Starting slots can move over supported terrain; their facing follows the authored checkpoint direction.

• Apply coordinates commits X, Height and Z together, avoiding invalid intermediate diagonal moves.

Validation and limits

• All forty variants pass wider relocation checks, including 854 original checkpoint-plane checks and 30 sector reassignment cases.

• Separate combined checks cover terrain, surfaces, scenery, pickups and race layout together. The 36 racing variants run 90 reconstructed three-car Expert/weapon ticks.

• The fallback rebuild is an offline editor policy. Native point counts, graph links, checkpoint order and lap flags remain unchanged.
