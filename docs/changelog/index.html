Track Viewer changelog

2026-10-25 · Choose any competing reversal branch

• Focus junction now frames all competing branch connections together, labelled A/B/C (and more when needed). Every branch can be selected, including either branch currently occupying a native slot. Nothing is preselected.

• Select a radio choice or click its label in the 3D view. The selected branch becomes amber; the other candidates stay cyan.

• Remove selected branch deletes that connection. Preview nearby free slot proposes a different owner; Move selected branch applies it after inspection.

• Removing or moving a branch already in a native slot gives the freed slot to a waiting branch. The other competing connections are retained automatically, and remaining overflow still blocks racing/export.

• Existing version-6 projects remain readable. Project save/load preserves the repaired connections, report and original draft snapshot.

2026-10-25 · Clearer connection gaps and larger path points

• Two-way branch connections now align their dash patterns, so opposite arrows no longer paint over each other's gaps. Short centred dashes occupy30% of each period, with70% left clear. Explore and Reverse track share the same pattern.

• Branch arrowheads sit within filled dashes so they also preserve the gaps when viewed edge-on.

• Path-point circles increase from7 to14 pixels across, doubling their radius. Point markers and merge/split shapes retain their separate toggles.

• GPU checks verify a visible dash and an empty gap with both connection directions drawn, plus the larger hollow circle's rim and transparent centre/corners.

2026-10-25 · Dashed connections and small path-point circles

• Cyan branch connections are dashed with arrowheads, so they remain distinct from solid route lines even when their colours are similar. Kept branch connections in Reverse track use the same dashed style.

• Point markers now draw small hollow circles in each group's colour. Their seven-pixel size stays constant as you zoom, and the Point markers toggle still controls them independently of arrows and optional merge/split shapes.

• Amber unresolved connections remain dashed, and the legends explain the line styles.

2026-10-25 · Optional merge/split shapes

• Explore → Show paths keeps its direction arrows and cyan branch connections, with merge circles and split diamonds hidden by default.

• Turn on Merge/split shapes to display those node decorations. Pending-connection diamonds follow the same toggle; dashed amber pending arrows stay visible with paths.

• Junction selection, connection counts and the single selected-point highlight remain available with the shapes off. The legend follows the toggle.

2026-10-25 · Explore AI merges, splits and directions

• Explore → Show paths now draws Rollcage travel direction arrows and cyan stored branch connections. Gold rings identify merges (several paths in); pink diamonds identify splits (several paths out). A point can be both. Lines that merely cross do not imply a connection.

• Inspect a merge or split lists actual graph points and their incoming/outgoing counts. Focus selected marker frames the junction and its neighbours with a white selection ring.

• The selected-point explanation separates normal travel through a group from the two stored branch slots, and flags merges whose incoming branch connections exceed that limit when reversed.

• Reversed drafts also show pending, unapplied connections as dashed amber arrows in Explore. Their counts stay separate from compiled native links and disappear when resolved or restored.

• Nearby routes in Reverse track are now brighter, thicker, outlined and directional, so they stand out against road textures.

Direction and branch decoding is enabled for Rollcage. Stage II and Firebugs keep their prior stored-point display; no unverified branch semantics are applied to them. All40 Rollcage resources pass raw-byte graph/direction checks and paired LOW/HIGH consistency. Browser validation covers HIGH/LEV1 controls, marker focus, reverse pending connections, GPU depth/visibility and resource cleanup. No game capture is needed for this viewer update.

2026-10-25 · Visible reversed-junction repairs

• Focus junction now shows labelled junction/destination markers, the pending branch as an amber dashed arrow, retained branches in cyan, and nearby route lines in grey. Markers remain visible through the scenery.

• Focusing a blocker selects its exact pending connection and opens a repair card explaining the two-slot limit and the branch that needs a decision. The card stays above the report list.

• Preview nearby free slot proposes an available point/slot without editing the track. Inspect the proposed path, then explicitly Retain branch or Remove this extra branch. Occupied slots are labelled and cannot overwrite an existing branch.

• Edit junction in Route points opens the matching point for manual inspection. Diagnostic markers disappear when leaving Reverse track or restoring the original draft.

This is an editor usability fix. Suggestions are starting points for manual review; they do not certify reverse-route driving. No native capture is needed for these display-only diagnostics.

Routes, checkpoints, assemblies and complete arrows

• Route points: clone an existing group, insert before/after a point and explicitly connect either outgoing slot. Cloned groups show their missing entry/exit connections; unfinished drafts can be saved, while Test changes and game export require valid connections.

• Route speeds: readable native thresholds, a separate Full throttle target and advanced raw bytes. Minimum is an AI candidate threshold; target controls throttle/braking and is not a hard speed cap.

• Checkpoints: add/remove logical checkpoints, choose finish and toggle timing feedback independently. Finish rotation changes starting-grid heading; the slot positions remain. At least two checkpoints are required. LEV12/13 keep topology locked because native code hardcodes checkpoint stages; their plane transforms and timing flags remain editable.

• Scenery: supported same-track destructible assemblies can be duplicated as a complete linked group, including LEV1 original-31 / original-32. Placement previews all parts and one undo removes the copy. Unsupported scripted dependencies remain locked.

• Surfaces: choose Single tiles / brush or Complete speed-pad arrows. Original mirrored arrow patterns support 90° rotations and one atomic placement, with UV corners corrected for the destination terrain. Tracks without a recognized original arrow have no pattern palette.

• Version 5 projects retain stable route/checkpoint identities, assembly commands and arrow references. Earlier project versions remain readable. Changes compile to LOW and HIGH together.

Validation covers all 40 track resources and browser editing/save/load/export workflows. Original-game LEV1 LOW/HIGH checks confirm rebuilt data and separate assembly construction; LOW runtime checks confirm finish/lap advancement with timing markers off/on, added-arrow acceleration, independent clone damage and attachment cleanup.
