# 2026-10-25 · Dashed connections and small path-point circles

- Cyan branch connections are dashed with arrowheads, so they remain distinct from solid route lines even when their colours are similar. Kept branch connections in Reverse track use the same dashed style.
- Point markers now draw small hollow circles in each group's colour. Their seven-pixel size stays constant as you zoom, and the Point markers toggle still controls them independently of arrows and optional merge/split shapes.
- Amber unresolved connections remain dashed, and the legends explain the line styles.
