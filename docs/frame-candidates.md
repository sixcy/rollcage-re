# Frame candidate arena

`src/frame-candidates.mjs` reconstructs the complete two-pass frame parent `0x4287f0`. `buildFrameCandidates(bodies, options)` first builds terrain candidates for every body, then builds model candidates for every body into the same retained arena. Defaults call the recovered terrain-region and placed-model algorithms. Options supply sphere `records`, parsed `grid`, `models`, and `arena: {entries, startOffset}`. Offsets are aligned byte offsets relative to `entries[0]`; entries represent native 16-byte records.

The parent refreshes aggregate cached position and velocity before object filters. It resets terrain/model counts, handles outside midpoint lookup using the body's prior registration, applies type17 radius changes, derives swept radius and signed-short midpoint, and preserves each region's nearest-vertex result. `body.collisionBound120` is the same native field reset to `INT_MAX` by `beginPhysicsFrame`; `closestTerrain11c` retains its prior value when no closer vertex is found. Runtime registry buckets require an explicit mapping back to their parsed static node through `spatialStateFor`; the installed-data probe demonstrates this mapping.

The native model cursor advances by the terrain count at `+0x15c`, although model append writes its count at `+0x15e`. Later model writes can therefore overwrite earlier model entries. This is preserved. `candidateArenaView(arena, body, kind)` reads the resulting shared storage rather than an isolated pre-overwrite candidate list. Consumers must retain that alias behavior.

`tools/verify-frame-candidates-instructions.mjs` checks 250 retained instructions over 1,400 fixtures and 871,558 interpreted steps. Spatial lookup and the two append routines are explicit deterministic boundary mocks; comparison covers every body byte, the sphere pool, shared arena, call order and arguments. It exercises signed collision counts, filter/reset order, outside transitions, type17 radii and overlapping model writes. Five focused tests cover integration with the frame reset, arena aliasing, retained entries and special branches.

`node tools/probe-frame-candidates.mjs` connects real append implementations on all 80 installed level packs: 1,220 batches, 3,660 synthetic vehicles, 21,960 registered sphere records, 41,196 terrain candidates and 860 model candidates. Independent stage outputs establish expected shared-arena writes, offsets, counts, closest state and aggregate cache; all pass, including spatial cleanup. Four actual model writes overwrite four earlier model views. Vehicles use recovered five-sphere descriptors and wheel-extended aggregate radii, declared initial positions/velocities and explicit allocation/registration state. No outside-stays-outside case occurs in this corpus sample; the native and focused tests cover it. This probe does not execute sphere contacts, responses or the original game.
