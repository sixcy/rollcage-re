# Renderer vertex declarations

`src/renderer-vertex-declarations.mjs` reconstructs the integer-keyed declaration cache/builder `52c3e0` and its actual node allocation/insertion descendants `52ce40`, `40c640`, `52ce70`, `40c9a0`, iterator predecessor `4061e0`, and RB-tree rotations including `405d40`. Evidence is retained in native-simulation replies 13301–13338 and the earlier weather iterator/rotation evidence, all for Redux SHA-256 `c0582271862ec373f00d01545c2a95aef0abb10a32513ec585271d08b10c6cf5`.

The cache is the map at manager `+a8c`, with count `+a90`. Keys are unsigned DWORDs `(textureCount << 24) | flags`; this deliberately admits collisions between high flag bits and texture count. The 24-byte nodes retain padding bytes, and a cached null declaration is still a cache hit. Allocation rereads both the map's root and the caller's pair pointer. Duplicate insertion deletes the new node without replacing the existing value or releasing the newly created declaration.

The original global element array at `7171a0` receives the ordered position, mask `20h`, normal, color, tangent pair, and texture coordinates, followed by the native `ff/11` terminator. Unlike the logical vertex layout, mask `20h` contributes 16 bytes here. Texture elements are emitted for the full unsigned count independently of mask `8`; the usage index is a byte and wraps at 256. Direct3D device method `158h` receives the original element array and output local; its HRESULT is ignored. The final return rereads the output local after allocation/insertion.

`tools/verify-renderer-vertex-declarations-instructions.mjs` passes **22,200 calls, 498 reached instructions and 3,167,124 steps** across 600 fixture worlds. It compares the full mapped byte range at and above `10000h`, defined returns, exact CRT/COM requests, and exception-chain restoration. It uses the actual game tree algorithms, including persistent mixed unsigned keys, left/right rotations, duplicate deletion, cached nulls, 260 texture elements, and allocator-side pair/root changes and competing insertion. CRT allocation/deletion/exception services and Direct3D are explicit services; no game function is mocked. Five focused tests cover the main recovered quirks.

This closes the declaration subgraph, not the whole renderer startup. Hardware vertex ownership/lock transfers are now covered by [renderer-vertex-buffers.md](renderer-vertex-buffers.md); material/shader creation, window setup and broader startup remain separate work. These are interpreted retained-instruction comparisons with synthetic memory and declared platform responses; the original executable and graphics driver were not run.
