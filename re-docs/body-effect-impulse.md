# First body effect impulse

`src/body-effect-impulse.mjs` reconstructs `0x47b020`, called by the first ordinary-preparation effect slot. `applyBodyEffectImpulse(body, options)` receives the runtime `originQ16` vector and signed `strength` explicitly. These correspond to globals `0x91cd80..0x91cd8c`; the routine does not invent their gameplay producer or meaning. `roundingMode` declares floating integer conversion for the active-vehicle branch. Optional retained `directionScratch` exposes shared globals `sum91d45c` and `leadingZeros91d460`.

The outer screen wraps position differences, shifts them right18, rejects squared distance above65536, clamps the denominator to at least256 and divides each reduced component shifted16 by that denominator. Absolute component sum below32 rejects the effect. Accepted components are multiplied by `strength>>2`, with signed product wrapping, then independently clamped to `[-6144,6144]`.

For ordinary type3 vehicles, `collisionCooldown66f` increases only when it is below signed `min(strength*8,255)`, retaining the native multiply wrap. On increase, `effectDirection680` receives the raw position difference. Real helper `0x417610` reduces large directions or conditionally subtracts `0x20000` from Z; it is not a generic normalizer. The real fixed vector-length path then selects `effectFallback674` below length64, otherwise normalizes the cache through `0x492d10`. Shared scratch first records417610's wrapped absolute sum/count, then is overwritten by the length callee's fixed-root input/count. The final exposed scratch preserves that overwrite.

Type3 writes `effectCounter6b8=16` and the unsigned-short sum of absolute clamped components into `effectMagnitude6ba`, even when cooldown does not increase. Types7 and12 instead halve components arithmetically. The ordinary path adds each component shifted8 to force and shifted7 to torque, then clears the collision flags high bit. Signed wrapping is preserved throughout.

`body.pairCollisionContext.stateByte6bc` supplies the explicit byte or null pointer sentinel. A nonzero active byte redirects type3 through the real `0x4343e0` float normalizer, shifts its Q12 output right4, and calls `handlers.onActiveVehicleEffect({body, directionQ8, effectCode: 0x70})`. It returns before updating the ordinary counters, caches, force, torque or collision flags. Operation `0x482730` remains an explicit external boundary; its gameplay/effect implementation has not been recovered. Even a zero-strength accepted effect reaches it, retaining masked-invalid float conversion behavior for a zero vector under the declared arithmetic context.
