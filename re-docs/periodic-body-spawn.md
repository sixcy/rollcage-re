# Periodic type33 body lifecycle

`periodic-body-spawn.mjs` reconstructs `469ec0`, `469fd0`, tail entry `46a140`, and the pointer-installed `46a2c0` contact callback in Redux 1.3.8.0. The controller is the single twelve-byte record at `903510`: body pointer, active age, sound handle. Session byte `554` gates initialization and updates. The constructor's caller is `47ea40` at `47eda2`; the complete startup caller remains open. No more specific gameplay name is assigned without further evidence.

The constructor takes one 384-byte body from the existing arena, sets flags `821`, installs the collision callback, initializes from original configuration `5ec318`, and removes its initial spatial insertion. It links body `+164` back to the controller and initializes age/index/timestamp to zero and sound handle to127. The literal configuration and one20-byte shape descriptor at `5ec920` are retained in `periodic-body-constants.json`. Runtime reads remain live; the initializer is an explicit convenience for supplying the original executable bytes.

An inactive spawn attempt changes its RNG/pose before spatial rejection. It chooses X/Z offsets from the selected player's stored short basis fields, places Y7200 units above the player, sets150-unit vertical momentum, and uses actual `479b30` to limit velocity before spatial/shape registration. The authored shape plus aggregate consume two physical IDs. Sector flag8 rejects activation. Sound30 passes through actual `484bb0` and the game's sound bank/channel logic.

Updates emit kind8 particles with count0 (the emitter still emits at least one), then set three cursor-relative particle lifetimes to16, independently of the number actually emitted. Unsigned incremented age greater than200 and the body's tagged outside flag separately call actual `46a2d0` retirement. The original simultaneous-expiry/outside state can attempt double unregister; it is preserved, not repaired, and lies outside the valid registry scenarios admitted by the connected checks. A strict unsigned clock gate requires `timestamp+600 < clock`; only then is the spawn-chance RNG advanced. A successful chance toggles the selected participant when session byte552 is nonzero. The native slot-index expression wraps to zero for all32-bit inputs; no multi-slot ring is invented.

`raw-linear-velocity.mjs` implements the exact raw `479b30` layout, numerical stack stores, signed `41ca60` root walk, and `41c990` divide. It preserves `abs(INT_MIN)`, overflowed squared sums, and arithmetic fault state. Its ABI takes the enclosing body rather than native ECX=body+34. The existing structured arithmetic API retains its documented mathematical domain. Numeric temporaries are written at their producer points; ABI saved registers/return addresses are not fabricated.

`46a2c0` is not a Ghidra procedure. A failed procedure query is retained as such. Four real `inspect_native_instruction` Listing decodes, independently checked against the complete16-byte read, prove `MOV ECX,[ESP+4]`, call retirement, zero EAX, return. `analysis/periodic-body-contact-listing.json` is a reference carrier rather than synthetic procedure Evidence. The callback adapter can bind to the shared physical views through `createPeriodicBodyCollisionFilter`.
