## Typed source boundary

It checks source-produced caller/frame/argument/IAT/known-save words, unchanged
original clock inputs and the complete eight-byte **source preimage**. It writes
only the actual eight external output bytes and returns the observed BOOL once.

no timer/game-function result is supplied.

clock and expected register values have private copies. Changing public metadata
or original observation buffers after verification cannot replace the API
outcome. An unbranded service, wrong caller, altered preimage, changed clock
inputs, unsupported API or repeated consumption fails before writing an outcome.

protocol callers retain their existing external-service contract. The source
