## Observer boundaries

Retained `278-physics-frame-assembly.json` proves this order:

| Address | Meaning |
| --- | --- |
| `474a46` | Call `440510`: reset queue/free cursors, retaining event bytes |
| `474a4b` | Call `427870`: build initial events |
| `474a50` | Load initial/live queue count at `902ba0` |
| `474ac7` | Call `474b20`: per-body filters, potentially replacing event bodies and delta |
| `474ad5` | Call `474bb0`: actual response dispatch |
| `474ada` | Dispatch return instruction |
| `474b12` | Call `475450`: finish body advancement |

At `474bb0` entry, `ECX` is the selected104-byte event pointer and signed `EDX` is the filtered time delta. The return word is the actual module address corresponding to `474ada`. Five pushes in the parent, one extra argument push and the CALL put dispatcher entry ESP exactly28 bytes below whole-frame entry ESP. `inspectNativeEventDispatch` validates those identities, event-pool alignment and bounds. A dispatch can still have null first/second bodies after filtering; a hit proves dispatch invocation, not an accepted physical impulse.

An observer-only host latch can select a naturally colliding frame: retain its earlier full entry snapshot on the host, observe one or more same-thread dispatcher hits whose parent ESP matches, then retain the corresponding full return. A breakpoint reached later cannot retrospectively capture entry state. Keep latches and counters in the capture wrapper, with no target-memory gameplay writes. Stopping at the first dispatcher entry gives only a partial parent frame and cannot replace a complete entry/return comparison.

The current matching-hit skip mechanism selects later complete native frames without needing this latch. Entry and exit skip windows must match and retain the observed matching-hit proof. The whole-frame boundary still excludes preceding AI/input/deformation producers and subsequent attachment/body-state/render submissions; independent native-entry replays do not establish an uninterrupted source-only tick or trajectory.

## Live source dispatch traces and direct native comparison

`stepSimulationFrame` accepts optional `context.onCollisionDispatch(record)` observations immediately before and after its actual `474bb0` response call. Records contain frozen primitive objects/arrays, including exact event/body addresses, body types, contact point/normal/scalar, classification/tag/delta and before/after pose/motion. Raw native frames also copy the exact104 event bytes to an immutable hex string. No live event/body references or writable buffers escape. When absent, the hook skips all snapshot construction. Callback return values are ignored; exceptions propagate.

The before record also identifies live terrain candidate rows matching the event's contact-cell reference, including their native type and plane normal. `tools/trace-native-frame-events.mjs` and its shared helper classify a terrain border only when the actual matching cell/normal candidates have type6/7. A horizontal normal or event class flag alone does not establish a wall. Ambiguous merged/edge normals remain unresolved.

`analysis/native-frame-dispatch-turn-20261022.json` traces29 actual source dispatch calls (13/9/7) from the retained original full frames at clocks348/349/350. Every call is kind1, involving type3 cars or type4 physical camera bodies; low classification bytes are1 or2 (swept/penetration). Model query count iszero. Twenty-six calls match actual terrain surface plane types0/3, and three have merged/edge normals that do not equal a single candidate plane. This evidence proves no car-car, body-pair or native type6/7 border dispatch. All three final expanded native frame comparisons still match.

`tools/check-native-event-frame-replay.mjs` checks a separate complete-frame capture containing direct native `474bb0` entries. It requires every observed event to lie between the paired entry/return ordinals, on the same thread, at parent ESP minus28, with the exact native caller and actual paired-frame clock. Fixed-clock captures additionally retain their clock predicate/root. Pending-frame captures retain final candidate/count identities and original observation order independently of deferred disk publication. In order, it compares the complete104 native bytes, actual event address and signed EDX delta with the source before record. Missing/extra events, order/ABI/clock mismatches and individual raw-byte differences fail. Source after records are diagnostic observations; native dispatcher-exit equality is not implied.

The first separate direct-event capture at clock348 contains **zero** native dispatch snapshots and zero source events. Its complete frame matches, but `analysis/physics-native-direct-dispatch-reviewed-20261022/report.json` records failed direct-event coverage (`no-dispatched-events`), rather than treating two empty lists as positive impact evidence. The earlier turn capture's event clock is therefore not a reliable natural-event selector across independent runs. A pending-before host latch, or a larger bounded consecutive capture with direct observations throughout, is required to select an actual event reliably.

The host-side pending-before latch subsequently selected a positive original frame. `analysis/physics-native-selected-collision-20261022/report.json` and the independent rerun `analysis/physics-native-selected-collision-independent-20261022/report.json` both match: clock348, **two direct native dispatch entries**, exact104 event bytes/actual addresses/signed deltas, and4,885,396 final semantic bytes plus native return. Matching live cell/normal candidates have native terrain type7, proving contact against the constructed right border. This is specifically **physical-camera/right-border** coverage. It does not prove car-chassis/wall, car-car or other body-pair dispatch.

`tests/native-frame-event-trace.test.mjs` verifies mismatch detection and frozen observer output. ## Explicit body-pair subset

The checker also admits an explicit pending-frame **kind0 body-pair substream**, using only a fixed four-byte `captureWhen` predicate at `ECX`, equal to `00000000`. Every retained event must prove that predicate address equals its actual event pointer and that the raw104-byte event kind iszero. Source dispatch observations are filtered by the same exact kind. Full source processed-event count must equal the pending group's **all observed** native dispatcher count, while source kind0 count must equal qualifying native snapshots. Ordered raw104 bytes, addresses and signed deltas still compare exactly. Empty subsets fail.

Reports label this scope `kind0-body-pair-substream`; native terrain dispatcher records omitted by that predicate are not claimed as compared. Ordinary pending full-stream mode continues requiring observed count equal qualifying count and rejects filtered snapshots. A kind0 record is classified as car-car only when both actual observed source body types are3; kindzero alone is insufficient.
