# Body attachment release

`src/body-attachment-release.mjs` reconstructs Redux `44ef90`, using actual `44d6a0` light-range removal and `4748d0` particle spatial removal. The parent captures the global light high-water count once, visits at most five live words at body+16a, and stops on a zero type nibble. Unknown types clear their handle. Type 1 removes light ID+1, clears its kind, and lowers the captured count only when it equals ID+2. Type 2 unlinks the referenced particle from its spatial bucket without freeing its pool record. Type 5 changes the script word to `(word & fff2h) | 2`. Each handle is cleared after its child; the captured count is published once on return. All later handles and script/pool references remain live memory reads.

`node tools/verify-body-attachment-release-instructions.mjs` matches 176 retained instructions over 2,400 fixtures and 358,398 interpreted steps, with 1,400 actual light removals and 1,700 actual particle unlinks. No external calls are substituted. Every byte above 10000h is compared; the interpreter's private stack below that boundary is excluded. Eight shared-storage cases cover script writes into later handles, the captured light count, light kind/range, dirty queue and particle predecessor, plus particle bucket and light-band writes into handles. Focused tests check early stop, the five-handle bound, captured count, particle lifetime preservation and live handle IDs.
