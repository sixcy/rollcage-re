# Renderer matrix arithmetic

`src/renderer-matrix-arithmetic.mjs` reconstructs recursive determinant 4a55a0, inverse 4a5430 and transpose helpers 52db70/52dc50 through their real constructor 4021b0. These are numeric dependencies of the game-owned renderer device's view/projection adapters. Their recovery does not close the device or its state-cache interface.

The determinant expands the first column, preserving four-float row stride in smaller minors and each binary32 operation. Actual inverse callers use dimensions 4, 3, 2 and 1; the exported determinant also preserves the native dimension<=1 first-element return and rejects dimensions above the recovered four-row workflow. A zero determinant copies the lazy shared identity. A nonzero determinant builds each cofactor from live source memory and writes output immediately. Consequently in-place inversion follows the original overwrite order; it is not replaced with a mathematically cleaner snapshot. Transpose captures inputs before its ordered temporary construction and four block copies.

`analysis/renderer-matrix-arithmetic-instruction-check.json` passes 2,400 fixtures, 350 reached instructions and 10,169,908 interpreted steps. It executes 99,800 actual determinant calls, 600 inverses and 600 calls to each transpose helper, with no external or game handlers. All mapped bytes at or above 10000h and actual EAX/XMM0 returns match. Cases include singular and ordinary finite matrices, disjoint/in-place/partial overlap output and three incoming stack addresses. Four focused tests check stride, identity fallback, binary32 inverse values, transpose overlap and a reduced native comparison.

The original inverse uses XORPS with a register loaded with the scalar 80000000h sign mask. The bounded interpreter admits that narrow form only with proven low64 mask bits; it preserves known low64 destination bits, invalidates stale scalar-double metadata and refuses to invent a full128-bit result. Focused tests cover raw payload sign flips and rejected mask/vector provenance. Raw NaN arithmetic payloads and dimensions above four are outside this instruction corpus. No original process execution was used.
