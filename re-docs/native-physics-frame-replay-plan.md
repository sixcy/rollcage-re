## Implemented declarative coverage scaffold

`tools/lib/native-frame-manifest.mjs` now exports `nativeFrameGlobalRegions`, `nativeFrameRootRanges({stackBytesBefore,...})`, `buildNativeFrameManifest(snapshot,{moduleBaseAddress,stackBytesBefore,...})`, and `compareNativeFrameRegions(manifest,expectedRanges,actualRanges)`. Input range rows contain actual `address` and verified `bytes` Buffers, as supplied by the existing capture loader; this module does not replace blob/hash verification. A snapshot may hold rows in an array or Map. The main-module base must be explicit or consistently recorded in the snapshot/ranges.

The root generator returns helper-compatible descriptors only. Its fixed queue lengths are the actual standard100-slot initializer sizes; the manifest builder independently reads captured queue capacity and requires complete corresponding spans. A changed native capacity therefore requires adequate capture coverage rather than silently using the bootstrap length. The body arena uses an explicit allocation-root readable region, and the builder requires that all allocation bytes predicted by the captured wrapped32-bit size producer are covered. The fixed pool layouts, refresh two-pointer list, physical trailing null, shape/queue cursors, phase4, six-participant limit,50-row world-record capacity and aligned body pointers are checked. Additional reached spans require explicit address/length/comparison/evidence descriptors; explicit extra module aliases must agree with the observed ASLR base. The512-pointer body registry at `70e200` and count `6e6b44` are captured; reached linked-body identities still require binding.

The resulting manifest records native addresses, canonical aliases, required regions with `mutable`/`read-only`/`abi-input` policies, list capacities, body storage lower bounds, observed counts and entry registers. Nonvehicle body declarations initially cover only the common180h layout; the captured complete arena remains available and reached extended layouts still require identity binding. The comparator checks all declared semantic bytes, reports the first owning-region/address divergence and excludes ABI scratch by default (`includeAbi:true` admits it). Read-only policy is declarative: the eventual replay harness must also check native entry/exit invariance where that policy is asserted. `additionalRegions` does not itself prove a callback or metadata mapping.

The attachment queue at `902040` uses an explicit `attachmentWindowBytes` observation bound (default1024, aligned4, at most65536 and rejected if it overlaps another declared global span). This is not evidence of native allocation capacity. Capture and compare the entire window including tails, require entry/exit count `6e6ba0` to fit, and fail if any source write needs uncaptured bytes. Other small static dependencies include actual trig/yaw tables, vehicle owners, particle/skid/recovery/light state and sound roots/constants; pointer roots alone do not satisfy reached profile, active-effect or sound-object descendants.

Success is deliberately reported as `core-coverage-validated-reached-dependencies-unresolved`; there is no whole-frame-ready result. Spatial/terrain/model descendants, linked-neighbor identities, effects/scripts/emissions, exact stack-depth evidence and numerical-operation admission remain explicit obligations.
