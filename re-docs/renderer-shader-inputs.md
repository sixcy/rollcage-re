# Shader-input record ownership

`src/renderer-shader-inputs.mjs` reconstructs actual `524220`, `5282a0`, `528450`, `528060`, `526a00`, `527f20`, `527150`, `5274d0`, `5275e0`, `527200`, `527e50` and `527300`. The original 44-byte records contain a code DWORD, owned narrow name/conversion, and three opaque DWORDs copied without recursive ownership. Main evidence: retained `13452`–`13461`, `13471`, `13484`–`13493` and `13498/13499`, bound to Redux SHA-256 `c0582271862ec373f00d01545c2a95aef0abb10a32513ec585271d08b10c6cf5`.

All APIs use raw addresses plus `{memory,scratchBase,services.libraryCall}` with actual native entry ESP. Construction/deep copy clear the separately owned conversion word; assignment keeps that word on self-assignment and otherwise follows actual narrow-string assignment. The three opaque words are loaded after string callbacks. Destruction frees only conversion/name storage, retaining the opaque metadata. Default construction stores code `-1`, an empty name and zero opaque words, preserving unrelated bytes/padding.

The vector implements aliased append rebasing, 1.5x growth with `05d1745dh` maximum, deep copy/destruction before old-array deletion, and post-delete caller-length reload. Growth retains its real required-count argument and tailcalls reserve at the original entry ESP. Resize destroys only the removed suffix or constructs defaults into additional capacity, reloading live vector lengths afterward. Clear destroys all logical elements then reads the live root for the new end, preserving capacity.

`node tools/verify-renderer-shader-inputs-instructions.mjs` passes **600 worlds, 10,200 entry calls, 738 reached instructions and 2,133,750 steps**. It compares all mapped bytes at and above `10000h`, meaningful returns, ordered genuine CRT calls with child ESPs and restored FS linkage. Cases cover populated SSO/heap records, shallow opaque metadata/deep names, alias append, self-assignment, allocation/free-side live header/caller-length mutations, repeated grow/shrink/default resize and persistent actual constructor→append→clear→destructor sequences. No game callee is mocked and no original process is run. Five focused tests cover the corresponding ownership and live-root boundaries.

The consuming shader-source/program constructor and effect metadata are still separate open renderer-startup algorithms; this package does not claim their closure.
