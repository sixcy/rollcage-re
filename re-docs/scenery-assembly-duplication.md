# Same-track destructible scenery assemblies

The editor can duplicate a supported ordinary destruction/linkage assembly, preserving its complete ownership closure and behavior. This is separate from class7 plain-model import. Version5 projects save one command in `assemblies`, with the existing model rows unchanged: `{id, sourceLevel, templateIndex, position, yaw}`. A command cannot save or delete half a chain. Cross-library special imports, scripted moving objects, script-trigger attachments and scripted light paths remain unsupported.

`instantiateSceneryAssembly(source, selectedIndex, {id, level, position, yaw})` returns the checked command, deterministic preview member rows (`<id>-member-<source index>`) and a dependency plan. `inspectScenery` exposes `assemblyDuplicable`, `assemblyMemberIndices`, `assemblyYawEditable` and `assemblyReason`. `compileSceneryEdits(source, models, {level, quality, assemblies})` returns compiled resources, member placement indices, and per-assembly group/attachment mappings. LOW and HIGH are compiled before the viewer changes its draft or undo history.
