# Procedural texture field, palettes and updates

`procedural-texture.mjs` implements `499760` field/phase construction, `499a90` palette construction, the full numeric `499b90` texture update, actual `499de0` parent, `408310` renderer lock adapter and `433d50` unlock adapter. The parent is bound as an outer default. `device-color-packing.mjs` implements actual `40a1e0`/`40a2f0` live renderer-format conversion; renderer resource creation and teardown remain separate requirements.

`499b90` writes128 rows of128 pixels starting128 row pitches into the renderer surface. It adds two packed four-byte field words, preserving inter-byte carries, then ORs `80808080`. Format8 stores that dword directly; format16 uses four live ushort palette entries at `7139b0`; format32 uses four live dword entries at `713bb0`. Writes/read order is explicit so output/input/palette overlaps retain native behavior. The phase at `6e6d00` advances by three times the signed delta and subtracts3600 once when the wrapped result is at least3600. It is not a modulus. Phase indexing masks the byte offset to16bits.

The parent gates on configuration byte28 and handle `5ed02c != -1`, captures a1–3-tick interval or falls back to1, locks through the actual game adapter and supports formats8/16/32. Unsupported successful formats are still unlocked. A failed lock still updates `5ed2c4` from the live final clock; a disabled stage does not. The game adapters resolve the mutable handle mapping and renderer manager on each call. Virtual manager90, resource lock8 and unlock12 are explicit renderer-library services; no game-owned adapter is mocked.

Native verification: `node tools/verify-procedural-texture-instructions.mjs` passes240 mixed parent/leaf cases,373 renderer calls,291 reached instructions and13,577,445 steps. All mapped bytes above10000h and exact service arguments/order compare. Includes input-field/output overlaps, leaf palette/output overlap, unsupported formats, missing mappings/resources, lock status low-byte rejection and live clock mutation. Parent output scenarios preserve the renderer pointers needed by its subsequent unlock; arbitrary pointer corruption does not establish a valid renderer lifecycle. Private ABI saved registers/returns are excluded. `STOSD ES:EDI` is admitted as a single dword store with DF=0, preserved ECX/flags and a focused interpreter test.
