# Shader-name and registration-pair ownership

`src/renderer-shader-names.mjs` reconstructs actual name lookup/registration `526f10/526b50`, manager adapter `50f3b0`, the complete 28-byte wide-name vector and its deep-copy/destruction/growth helpers, and the parallel 8-byte opaque-pair vector. It uses the independently recovered raw wide-string algorithms from `game-wide-string-buffer.mjs`. Main evidence: retained 13396/13397, 13418/13419, 13444–13449, 13466–13483 and earlier `4a29b0` pair-copy assembly. Target SHA-256: `c0582271862ec373f00d01545c2a95aef0abb10a32513ec585271d08b10c6cf5`.

`registerRendererShaderName(cache,name,first,second,runtime)` searches with genuine CRT `_wcsicmp`, returning a one-based index. A hit leaves the original pair unchanged. A miss constructs the raw wide-name temporary, deep-copies it into cache vector `+100c`, destroys the temporary's independently owned conversion/storage pointers, then reads the live two caller words and appends them to vector `+1018`. The return derives the name count from the final live header. `registerRendererManagerShaderName` is the actual manager `+360` adapter.

Wide vectors grow by the original 1.5x policy and `9249249h` size bound. Reallocation deep-copies names through actual `40b600`, destroys all old owned conversion/name pointers, then frees the old array. Pair growth uses bound `1fffffffh`, forward DWORD stores and no name construction. Appending an existing element preserves its relative index and rebases after reallocation. Both reserve helpers overwrite the incoming capacity argument with the old logical length and reload it after destruction/deletion; this matters under raw aliases and declared service-side mutations.

The lookup reads the live vector root and logical count after each comparator return. Native null-name matching still belongs to the CRT contract: a null is substituted with the empty literal only after a cache miss, so the reference does not invent null-safe behavior for an existing-name comparison.

`tools/verify-renderer-shader-names-instructions.mjs` passes **6,600 calls, 852 reached instructions and 1,920,791 steps** in 600 fixture worlds. All mapped bytes at and above `10000h`, meaningful returns, ordered CRT calls and core child ESPs match. It includes 600 actual `525b90` cache constructors followed by persistent registration/repeat sequences, aliased append, heap/SSO names, case-insensitive hits, old owner retirement, comparator-side end changes, allocation-side header changes and post-delete caller-word/length mutation. FS linkage is restored. The shared cache constructor retains its separately proven narrower CRT-frame contract: its nonmutating memsets and allocation child ESPs are not newly claimed by this comparison. Five focused tests cover ownership, hit behavior, rebasing and live metadata.

No game callee is mocked and the original executable is not run. This closes name/ID/pair ownership, not `525f70` shader-source generation/compilation, effect metadata, material property-vector copying or the full renderer startup.
