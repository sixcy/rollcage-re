# Projectile guidance and normalization

`src/projectile-guidance.mjs` reconstructs `46bad0`, `44c210`, and `44bff0`, using raw shared bytes and native entry `scratchBase`. The route-motion tail calls actual `46b070` from `wormhole-visuals.mjs`; it does not accept a supplied orientation result. `src/raw-vector-normalization.mjs` supplies pointer-based `422c70`, `492cc0`/`492d10`, and `41c9c0` behavior.

`422c70` returns the input reduction **shift** in EAX, changes the input in place, and publishes `91d45c`/`91d460` before reloading it. `46bad0` uses half this shift to choose damping and transition state2 to32 with timer16. A live type3 target gets a `200000h` vertical subtraction. This is not a Euclidean distance threshold. Signed overflow and masked invalid FISTP output are preserved; fixed normalization of a zero vector retains its division fault.

`44c210` subtracts position high words from authored signed-short XYZ, then adds packed signed three-bit directions. The packed Z word is captured after the first output store, while the packed XY word is read after all three initial stores. Output aliases can therefore change the XY direction without changing the already captured Z direction. `44bff0` normalizes the mutable steering vector, derives curvature from two actual authored direction vectors, applies wrapped Q16 damping and force, and rebuilds orientation from resulting momentum. Mode changes also affect the steering vector itself.
