# Autonomous dispatcher and smaller modes

`src/autonomous-dispatch.mjs` reconstructs Redux 1.3.8.0 `410220`, including the actual `420020` pickup-use prepass, `4355c0` shared event update, `430930` mode `200`, `430970` mode `40`, `41f130` start timer and `430ae0` mode `20`. This is retained-instruction reconstruction, not original-process runtime evidence or a complete autonomous driver.

## Dispatcher ordering and boundaries

`runAutonomousDispatch(body, {memory, scratchBase, handlers})` uses numeric addresses in a supplied raw Buffer. `scratchBase` is native entry ESP. Initialize the two retained probability/shift tables explicitly with `initializeAutonomousDispatchTables(memory)`.

The dispatcher captures unsigned clock `90a548`, clears mode bit `4000` and the entire control dword `710`, performs the scheduled `41f900` call when `clock % 120 == vehicleIndex * 16`, then runs the pickup prepass. Its once-per-clock update compares global `6e6510` against the captured clock, even if a callback changed the live clock. The shared stage receives the actual ECX left by `420020`. Byte `6d9` cycles through 0..5; all starting values above 4 become zero.

Mode selection uses live mode word `6c4 & 3ff`. Modes `20`, `40`, `80` and `200` return after their respective callees. Modes 1/2 return early when `4311e0` returns nonzero. Mode `100` decrements its unsigned timer and returns with control bit `40` while the resulting timer is at least 30; otherwise it reaches common planning. Common planning calls `47fc20`, `47ff20`, then `41f0d0`; phase zero additionally calls `421430` and, if the live phase remains zero, `4103f0`. It finally sets mode bit `4000`.

All eight former game boundaries now bind actual defaults: `41f900` scheduled profile planning, `421430` candidate scoring/selection, `4103f0` weapon-use policy, `47fc20` route connectivity, `47ff20` stuck detection, `41f0d0` random recovery, `47ffb0` reverse recovery and `4311e0` power slide. Handler requests contain `{memory, ecx, edx, args}`; an overridden gate `4311e0` requires explicit EAX. Optional overrides support boundary probes. An overridden prepass must return `{ecx}` when the shared stage is reached. See [profile planning](autonomous-profile-plan.md), [route planning](autonomous-route-planner.md), [weapon policy](autonomous-weapon-policy.md), [connectivity](autonomous-route-connectivity.md) and [recovery](autonomous-recovery.md). Native initialization of the supplied state and complete outer-tick integration remain open.

## Recovered children

- `420020` advances RNG `5ea4d4` by `imul(seed,16807) & 7fffffff`, reads profile bits 6..8 from body `6f8`, and uses shifts `[8,9,10,11,12,13,14,16]`. Selection 0/1 can OR primary/secondary pickup input bits 4/8 when the corresponding slot is nonzero and its previous-input bit is clear. Profile capture occurs before writing the seed; this matters for raw-memory aliases. The exported register result preserves EAX/ECX/EDX consumed by the parent.
- `4355c0` visits authored eight-byte event rows backwards. Type 2 / flag 1 rows advance five directional route points with actual `491470`, then scan session records for active body state 10 on the same route and within one point of the result. A match clears the row flag. `491470` advances N points atomically; it is not a typed-point search. Failure leaves the output low word untouched. The initial ECX stack write and retained output bytes are preserved.
- `430930` clears the full mode/timer dword at timer 20; otherwise it increments the timer and replaces the entire control dword with `(oldLowWord & 5fbf) | 40`.
- `430970` preserves distinct word/dword clears across session phases. Its countdown has an exact no-op tick at `228 - clock == 69`; tick 68 chooses `41f130`'s profile-dependent timer. Earlier ticks can allocate a capped random timer while the signed active counter is below two. Probability bytes are `[200,100,50,30,20,15,10,5]`; a successful allocation consumes two RNG transitions. Profiles 0..3 of `41f130` also consume two transitions, profiles 4..7 one.
- `430ae0` increments its unsigned timer. Above 120, it restores route/progress on the body reloaded from the indexed race record, which can differ from the current body, and clears the current mode/timer dword. Otherwise it selects the last matching authored type-4 event, computes actual route direction and normalized target delta, and compares both fixed-point dot products against `f746`. Pickup 4 may fire primary or secondary. A blocked primary slot does not fall through to secondary. Missing events use point zero after clearing the mode word. Non-timeout paths set bit `4000`.

## Evidence and verification

Main dispatcher assembly is `204-autonomous-vehicle-assembly.json`, Evidence `ev_210f838d76927d45f47e9d2a81d3284a9b992341e088456ddcbc02e24f8c2430`. Child assembly is retained in results 252, 254, 256, 258, 265 and 267. Switch/probability/shift bytes are retained in 250, 259, 260, 263 and 268. Five-point advance is `301-autonomous-typed-point-assembly.json` (the preliminary filename predates the recovered N-point behavior), Evidence `ev_875c36ac251daa7c550719cf9545d2cb9268e3845425d463ee9ee02b9e963df9`; related route helpers are documented in [autonomous-route-control.md](autonomous-route-control.md).

`node tools/verify-autonomous-dispatch-instructions.mjs` executes 1,172 retained instructions across 4,900 synthetic entry fixtures plus one explicit profile/seed alias fixture: 447,887 interpreted steps, all matching. It executes actual five-point advancement, route geometry and fixed arithmetic. It compares complete body regions, record storage, event/route/session regions, globals and boundary call arguments/order. The fixtures include 588 shared queries, 129 row disables, 255 mode-20 geometry passes, 80 fire writes and 350 timeouts. Eight named state-mutating fixtures deliberately override the now-recovered defaults. This caller check establishes interface/ordering behavior; dedicated profile/planner/weapon/connectivity/recovery checks establish the implementations. The separate connected dispatcher checker uses actual defaults across persistent ticks and retains its supplied-runtime-state boundary.

`node --test tests/autonomous-dispatch.test.mjs` passes17 focused tests covering ordering, callback mutations, gate returns, unsigned thresholds, mode-clear widths, RNG consumption, raw aliases, route traversal, timeout destination identity and actual default connectivity/recovery bindings. Report: `analysis/autonomous-dispatch-instruction-check.json`. No original game process was executed.
