The independent flag scanner folds ASCII lowercase and consumes the mismatching code unit before restarting. Consequently `aaab` does not match `aab`. Value extraction instead uses genuine case-sensitive CRT `wcsstr`; the following character must be an original separator: space, `=` or `:`. It removes one separator, trims spaces/tabs, and then handles a quoted value or stops at the first space. An internal tab does not terminate an unquoted value. Quoted extraction finds the closing quote after trimming the temporary interior, but applies that count to the original string: `-Width="  1280"` yields `  12`. These quirks match retained instructions and are kept deliberately.

Wide temporary constructors initialize native fields individually;4a3000 leaves the extra-owner word untouched. Heap moves transfer the pointer, reset source length/capacity and preserve both extra-owner words. Inlined cleanup and the full destructor remain separate because only the latter resets the string fields. Native temporary addresses and child entry ESPs are preserved. `initializeRendererCommandLineConstants` maps the original separator table and empty wide literal from13236/13237.

The raw APIs accept `{memory,scratchBase,services}`. `getRendererCommandValue(output,key,runtime)` returns the output object; `getRendererCommandInteger(key,runtime)` returns the CRT-converted integer. GetCommandLineW remains an explicit platform service, and `wcsstr`, `_wtoi` and allocation/free remain genuine CRT services. The reference does not read the host command line itself.
