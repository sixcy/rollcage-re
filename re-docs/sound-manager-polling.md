## Remaining module work

_beginthreadex is a declared CRT service producing synthetic thread handles/IDs. The fixture does not launch a thread, wait for scheduling, initialize an audio device or execute the original game. The separately retained4a3320 entry calls4a38c0, and4a3790 polling tick calls4a94a0, which jumps to the substantial4a6600 manager update. These asynchronous game consumers and4ab7c0 queued callback invocation are not implemented by this startup package. Native exception unwinding and opaque CRT/Win32 internal frames are outside the declared library-service contract. Decoder/WAV/AIFF/ADPCM/OGG/MP3/backend branches beyond the empty startup descriptor remain separate reconstruction work. Synthetic allocation/QPC/locking/event behavior is proof input, not evidence of original-process scheduling or device output.
