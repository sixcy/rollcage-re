# Directional AI path visualization

Delivery15, 2026-10-25. Explore → Show paths now includes recovered Rollcage group travel and explicit branch connections. Existing group IDs, point coordinates, point-marker toggles and group filtering remain available. Other games keep the prior consecutive-point interpretation; Stage II explicitly disables this Rollcage graph adapter and experimental Firebugs paths never opt in.

`src/track-path-connectivity.mjs` reads normal travel from group byte2 (direction) and byte4 (cyclic wrap), matching recovered `491390`. It reads both14-bit branch fields in point DWORD+12, matching `47fc90`. Group0 is retained in the common stored-position display but excluded from the native AI graph. Duplicate destinations are counted once in graph degrees while both used branch slots remain recorded. Invalid target identities are reported and omitted from the arrows rather than assigned invented coordinates. All40 original resources have no invalid links in the retained matrix.

Merge/split shapes are optional and off by default (delivery16). With that toggle on, gold circles mark more than one incoming graph edge; pink diamonds mark more than one outgoing edge. A node may be both. These degrees include normal travel along the group. The two stored branch slots are a separate constraint: the selected-marker explanation shows incoming branch connections and outgoing slot usage explicitly. A merge with more than two incoming branch connections explains why transposing those connections during reversal can exceed that limit. Paths crossing geometrically are not connected unless linked in the stored graph. Available edges do not predict runtime choices under speed, blocker, recovery or weapon conditions.

For editor drafts, `withPendingPathConnections` maps stable project point IDs to the compiled native group/point order. Unresolved reversed connections stay separate from native edges and render as dashed amber lines. The graph adapter never applies a pending connection or changes game/project resources. Restoring/resolving a draft refreshes the display from current compiled geometry and report metadata.

`path-topology-overlay.mjs` builds static per-group/pair geometry buffers, including group direction heads, cyan branch arrows, nested merge/split markers and a white selected-marker ring. Outlined screen-offset strokes improve contrast without relying on unsupported WebGL wide lines. The shader offset resets after each stroke; normal depth behavior follows Show through terrain, and the path pass preserves depth writes/testing. Reverse-track nearby context also uses outlined bright two-pixel arrows. Existing model collision overlays retain their original style unless they explicitly request those strokes.

Delivery17 draws branch shafts as dashed cyan lines with solid arrowheads; normal group travel remains solid. This style also applies to retained reversal branch previews. Their size is independent of camera zoom; the existing Point markers checkbox controls them.
